Capstone project

Bank customer churn prediction

A classification model that flags retail banking customers at risk of leaving, trained on 28,382 accounts with an 18.53% churn rate. I compared logistic regression, random forest, and XGBoost using GridSearchCV and class weighting to handle the imbalance, and engineered a feature that ended up driving 39% of the final model's predictions.

  • 0.84ROC-AUC
  • 0.70Recall
  • 28,382accounts

Python · Pandas · scikit-learn · XGBoost · imbalanced-learn

Kaggle competition

Bahrain property rent prediction

An end-to-end regression pipeline forecasting monthly rent for 10,578 Bahrain listings. The hard parts were the data, not the model: numeric fields stored as text, and a target spanning 50 to 400,000 BHD that needed a log transform. I engineered high-cardinality location and agency features, then tuned a Ridge model with GridSearchCV.

  • 100 BHDtest MAE
  • 0.77R²
  • 10,578listings

Python · Pandas · scikit-learn · Pipelines · GridSearchCV

View the code

Investment analysis

Which startups raise again?

A screen for venture investors, built from Crunchbase company records. I cleaned the data, defined which seed-stage startups went on to raise follow-on funding, and tested where the signal actually sat across industry, geography, and timing. Combining those filters lifted the historical follow-on rate from roughly 41% to 60%.

  • 60%screened follow-on rate
  • 41%base rate

Python · Pandas · NumPy · Matplotlib · Seaborn

Team build

Track Your Plant

A Streamlit web app for logging plants and their care history, built with a team. It stores records in CSV and works out overdue-care alerts from each plant's watering frequency and last-watered date, so the reminder comes before the plant suffers.
